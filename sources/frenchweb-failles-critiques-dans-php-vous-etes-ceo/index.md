#### What the page says

_Curator's reading of the capture._

A French business-technology piece (FrenchWeb, 22 October) written for company chief executives on what to do about the PHP flaws. It says CERT-FR issued an alert on 21 October for the two critical flaws, with fixes released the same day, and that European authorities ask for priority on exposed systems. It stresses that the presence of PHP proves neither an intrusion nor a lasting vulnerability if the fix has already been applied, that the website and the PHP software behind it are separate, that responsibility is often split between agency, host and maintainer so the chief executive should obtain a precise answer per service, that PHP can also run administration interfaces of cameras, building-management and network equipment (the maker or integrator must confirm each case), that GLPI fixed its cloud offer on 21 October but self-hosted installations need a PHP update, and that the UK NCSC recommends hunting for signs of compromise and persistent access.

> La présence de PHP ne prouve ni une intrusion ni une vulnérabilité persistante si le correctif a déjà été appliqué.

_Curator's translation:_ "The presence of PHP proves neither an intrusion nor a lasting vulnerability if the fix has already been applied."
