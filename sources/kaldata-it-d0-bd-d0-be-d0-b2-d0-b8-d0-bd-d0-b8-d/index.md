#### What the page says

_Curator's reading of the capture._

Kaldata (Bulgaria, Bulgarian), 26 October, by Emil Vasilev: the PHP flaws are now used in real attacks, with successful breaches. It relays BleepingComputer: Perplexity's Adel Karimi reported that his decoy servers recorded a successful attack on Apache mod_php with PHP 8.4.26, in which the attacker extracted about 800 KiB of process memory and then used an extracted function address in a following request, the server running the shell command about 1.6 milliseconds after the last byte; Expel's Marcus Hutchins confirmed the result. Cloudflare, Hadrian, watchTowr, Previdian and Patchstack had earlier reported attempts that had not led to successful exploitation, and Amazon had seen the first attempts on 17 October, four days before the fixes. It also describes the PHP security team's mitigation advice for a third flaw (CVE-2026-115560) that affects systems with an unusual configuration and has no patch yet: set session.upload_progress.enabled to 0 until it is fixed. A social-media post embedded in the page, an apparent tweet from a researcher about confirmed activity from the same IP and a second IP, is part of the article's embed.
