#### What the page says

_Curator's reading of the capture._

AtPress (Japanese press-release service), 26 October: a press release by Electronic Service Initiative (ESI), Okayama, which sells extended security maintenance for end-of-life PHP. It says it ported the two security fixes from PHP 8.2.35 to all PHP 5.3 to 8.1 versions and released them on 23 October (release esi-8.2.35). It says the upstream advisory lists only the supported 8.2 and later, but ESI's investigation confirmed the underlying structure exists in all end-of-life versions 5.3 to 8.1; the upstream fix is about 390 files and over 10,000 lines and had to be rewritten per version; some behaviour changes, as upstream, such as what happens at the memory limit; release notes need a subscription. It plans a hardening patch for related issues found during verification and a check of PECL modules. Commercial and promotional in tone.
