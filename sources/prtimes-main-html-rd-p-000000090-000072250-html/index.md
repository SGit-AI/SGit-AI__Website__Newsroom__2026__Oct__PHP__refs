PR TIMES (Japanese), 26 October: a press release by Cohesity Japan giving the view of its global cyber-resilience vice president James Blake. It says the flaws can affect web servers and also network devices and security products that use PHP, that mod_php deployments may be under-inventoried, that financial institutions use PHP like other firms and may be affected though layers such as WAFs and jump servers reduce but do not remove the risk, that stolen passwords and API keys are possible, that shared servers can spread harm between sites, that unsupported PHP 5 and 7 are hard to fix and that systems that cannot be updated should be cut off from external networks; it stresses checking for existing intrusion, not only patching.
