#### What the page says

_Curator's reading of the capture._

A long plain-language explainer on HackerNoon about PHP2Shell, written without payloads or step-by-step detail. It gives the patched versions (8.5.12, 8.4.27, 8.3.36, 8.2.35), notes that PHP 8.1 and older no longer get updates from the PHP project and that php.net says there is no complete mitigation, relays Wiz's estimate that about 70% of websites run PHP (which the BBC said it could not independently verify), and sets out a UTC disclosure timeline: CVE ids circulating from about 15:00 UTC on 20 October with a wrong release time and a CVSS of 10.0, a pre-announcement at 19:30 UTC, release brought forward from 22 to 21 October at 14:00 UTC, a mistakenly published proof-of-concept video, and Chainguard's publication of built images with the fix at 07:41 UTC on 21 October, more than six hours before the coordinated release, which the PHP Foundation describes as breaking the embargo (disputed by Chainguard's leadership). It adds that Amazon's honeypots logged an exploitation attempt as early as 17 October, and describes the outages operators chose as precaution.

> PHP 8.1 and older no longer get updates from the PHP project itself.
