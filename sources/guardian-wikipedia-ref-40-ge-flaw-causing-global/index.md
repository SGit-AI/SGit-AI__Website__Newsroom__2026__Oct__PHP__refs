_Curator's reading of the capture._

The Guardian, 22 October: what PHP is and how serious the flaw causing website shutdowns is. It says sites in Canada, Japan and Germany were taken down temporarily while a fix was applied; quotes the PHP Foundation that the issues 'sit in parts of PHP that nearly every request touches: memory management and error handling'; says the vendor Hadrian labelled the pair a 'PHP2Shell exploitation'; quotes the US NSA that the memory corruption could 'provide a direct path to the server's file system or database'; and says the PHP Foundation said a number of security companies broke the embargo after the leak, while Amazon identified an attempt dating to four days before disclosure. On discovery, it says the PHP Foundation worked with Anthropic's frontier model to scan its code and had PHP put into OpenAI's programme.
