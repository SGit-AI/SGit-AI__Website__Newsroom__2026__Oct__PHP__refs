#### What the page says

_Curator's reading of the capture._

Pplware (Portuguese, SAPO), 21 October: urgent updates for the two PHP2Shell flaws. It says the two CVEs relate to memory management and the handling of internal data while processing HTTP requests; that Wiz researchers say the problems existed for decades, but the complexity needed to demonstrate exploitation hindered discovery of a working attack, and that advanced AI models helped overcome some technical difficulties; that PHP-FPM, Apache mod_php, php-cgi, FrankenPHP and LiteSpeed set-ups are affected, mod_php especially, where remote code execution was demonstrated with a single unauthenticated request before application code runs.

> Segundo os investigadores da Wiz, os problemas existem há décadas, mas a complexidade necessária para demonstrar a sua exploração dificultou a descoberta de um ataque funcional.

_Curator's translation:_ "According to Wiz's researchers, the problems have existed for decades, but the complexity needed to demonstrate their exploitation made it hard to find a working attack."
