#### What the page says

_Curator's reading of the capture._

Teknófilo (Spain, Spanish), 22 October, by Luis A.: two critical PHP flaws led to services being disconnected preventively while owners applied the fixes. It says the updates were published on 21 October, that the flaw sits in the engine so it can reach sites whose code and CMS are up to date, that both CVEs score 9.2 and allow remote code execution without logging in under some conditions, that the UK NCSC advisory explains the memory-management and failure-handling causes, and, citing Wiz, that process memory (passwords, tokens, access keys) can be read. No new facts.
