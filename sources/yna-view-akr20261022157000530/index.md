#### What the page says

_Curator's reading of the capture._

Yonhap News (Korea, Korean), 22 October: South Korea's Personal Information Protection Commission urged public bodies and companies that process personal data to protect against leaks over the PHP2Shell flaw. It says the flaw lets an attacker run malicious commands on a web server without login and could expose personal data in connected databases, especially if DB admin tools such as phpMyAdmin are exposed or the web account has excessive DB rights; the Commission recommends checking PHP versions and applying the latest patch, removing unneeded web services, blocking direct internet access to DB admin tools, minimising the web service account's DB rights, checking for bulk queries or exports, and checking PHP in outsourced and hosted systems; its secretary-general warned of large-scale harm to many users' data. The agency's copyright line prohibits AI training and use of the article: a licensing notice, nothing in the article addresses a reader.
