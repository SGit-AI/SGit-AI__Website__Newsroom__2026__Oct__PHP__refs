Source · advisory · primary · captured

RCE via stale global state (CVE-2026-109619)

PHP (php/php-src GitHub security advisory, published by bukka) · https://github.com/php/php-src/security/advisories/GHSA-6wmf-4rv5-p3rp · published 2026-10-21T13:34:13Z · added by collector-primary · slug github-ghsa-6wmf-4rv5-p3rp

CVSS v4 9.2, same vector as 109618. Use-after-free of worker global state across requests. Confirmed RCE mod_php (PHP 8.5 fatal_error_backtraces path) and session upload progress path on mod_php and FPM. GitHub API blocked; timestamp from page.

What it says, as the collector read it

GHSA-6wmf-4rv5-p3rp (CVE-2026-109619): notes

  • URL: https://github.com/php/php-src/security/advisories/GHSA-6wmf-4rv5-p3rp. Title "RCE via stale global state". Published by bukka; page time element 2026-10-21T13:34:13Z. Captured 2026-10-22T08:09Z. GitHub API blocked for this session.

Key facts (verbatim)

  • Affected "< 8.2.35 / < 8.3.36 / < 8.4.27 / < 8.5.12"; patched 8.2.35, 8.3.36, 8.4.27, 8.5.12.
  • "Critical 9.2 / 10", "CVSS:4.0/AV:N/AC:H/AT:P/PR:N/UI:N/VC:H/VI:H/VA:H/SC:N/SI:N/SA:N", "CVE-2026-109619". CWE-416/755/824/1325/1419 (same list as 109618).
  • Credits: reporters sagitzadik-wiz, tomash-areion, lcfr-hax, amyb-oai; remediation developers arnaud-lb, iluuu1994, bukka, ndossche.
  • Class: worker global state referring to freed request memory, "causing a use after free. A strategically crafted heap layout can produce full remote code execution (RCE)." Needs a producer and a consumer in different requests on the same worker.
  • Confirmed cases: "PHP 8.5 fatal error backtrace: confirmed ... the basis of the confirmed mod_php exploitation"; "Session upload progress lifecycle: confirmed"; "Session lifecycle RCE was validated against mod_php and FPM."
  • "Session upload progress is enabled by default, and no application call to session_start() is required."
  • Mitigations: fatal_error_backtraces=0 (8.5), session.upload_progress.enabled=0, pm.max_requests=1; "Updating ... is the only reliable mitigation."
  • "The confirmed impact is unauthenticated heap use-after-free, memory disclosure and remote code execution with the web worker's privileges."
