#### What the page says

_Curator's reading of the capture._

TurboLab.it (Italian), updated 22 October 20:50, by massimo.valenti ('human author, AI support'): Amazon detected exploit attempts four days before the patch. It says an Amazon honeypot already recorded a PHP2Shell attempt on 17 October, found by analysts on Wednesday by looking back over MadPot sensor data, from an IP address tied to a commercial anonymisation network and geolocated in Australia, and quotes Amazon's CISO CJ Moses that a honeypot targeted from an anonymised IP while the flaw was still under embargo suggests an attacker was behind it, though it is unclear how they obtained exploit information before disclosure. The practical lesson drawn is that the advisory date is not the start of the risk, so administrators should check logs back from 17 October.
