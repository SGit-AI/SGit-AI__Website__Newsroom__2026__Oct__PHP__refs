#### What the page says

_Curator's reading of the capture._

Ziua Veche (Romania, Romanian), 22 October: Romania's National Cyber Security Directorate (DNSC) has issued an alert on the two PHP flaws, rated 9.2 on CVSS 4.0, that can allow unauthenticated remote code execution; patches were published on 21 October. It cites CERT-EU's warning, notes versions 8.1 and older no longer get project updates, says several government sites and online services in Europe and elsewhere were temporarily unavailable or taken down preventively (Reuters), and recommends identifying the PHP version, backing up, updating PHP separately from WordPress and plugins, examining security logs, and, where updating is not possible at once, considering temporary isolation (CERT-EU). The DNSC alert refers to Law 58/2023, article 5(a), on responsibility for the security of IT systems.
