#### What the page says

_Curator's reading of the capture._

Stadt-Bremerhaven.de (Caschys Blog, German), 22 October, by Carsten Knobloch: Synology has published a statement on PHP2Shell after an investigation by its PSIRT, saying the flaws affect only NAS systems that run certain packages with a PHP dependency (Calendar, IDrive (third-party; Synology Drive itself is unaffected), Joomla, KodExplorer, MailStation (needs a manual update via Package Center), MediaWiki, phpMyAdmin, vtigerCRM, Web Station, WordPress). Synology has released PHP security updates for DSM 7.4, DSM 7.3 and the out-of-support DSM 7.2; older DSM users should disable the affected packages until they upgrade. Synology says DSM's own PHP component has no externally reachable modules and rates that risk minimal, with a patch planned for future DSM versions (advisory Synology-SA-26:14). The blogger adds there are reports that this is not the end of it.

> Nach einer Untersuchung durch das hauseigene Sicherheitsteam (PSIRT) steht fest, dass die Sicherheitslücken nur NAS-Systeme betreffen, auf denen bestimmte Pakete mit PHP-Abhängigkeit laufen.

_Curator's translation:_ "After an investigation by its in-house security team (PSIRT), it is established that the vulnerabilities only affect NAS systems running certain packages with a PHP dependency."
